# Qwen2.1 Align

ComfyUI/custom_nodes
`git clone https://github.com/CoreyCorza/Qwen2.1-Align.git`

Uses OpenCV SIFT feature matching and RANSAC to estimate one global affine transform, correcting translation, rotation, independent width/height scaling, and shear.
Significant edits might cause it to fail as it requires before/after images to contain matching areas need for realignment.
